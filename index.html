Desarrollo de Software — Calidad de Software

Calidad de Software

Llevada a producción industrial, con GitHub como columna vertebral

Cada módulo agrega una capa de calidad real al mismo repositorio del alumno: pruebas, integración continua, análisis estático, seguridad y observabilidad —en Python, C++ y Flutter/Dart en paralelo—, hasta terminar con un pipeline completo de producción, no ejercicios sueltos. El flujo de trabajo colaborativo en GitHub (ramas, pull requests, code review, Actions) se practica desde la semana 1, no se explica solamente. Es un curso de Ciencia de la Computación: aquí se construye software real, a escala industrial, no solo se habla de él.

◈ 8 Módulos ⬡ 16 Semanas
Repositorio base del curso: todo lo que construyamos este ciclo parte de github.com/ecuadros/2026-II-CS-UNI-SoftwareQuality — revísalo antes de empezar el Módulo 1, ahí se centraliza la información oficial del curso (sílabo, anuncios, cronograma) además de este material interactivo.
