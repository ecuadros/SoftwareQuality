Ingeniería — Calidad de Software

Calidad de Software

Llevada a producción industrial, con GitHub como columna vertebral

Cada módulo agrega una capa de calidad real al mismo repositorio del alumno: pruebas, integración continua, análisis estático, seguridad y observabilidad —en Python y C++ en paralelo—, hasta terminar con un pipeline completo de producción, no ejercicios sueltos. El flujo de trabajo colaborativo en GitHub (ramas, pull requests, code review, Actions) se practica desde la semana 1, no se explica solamente.
